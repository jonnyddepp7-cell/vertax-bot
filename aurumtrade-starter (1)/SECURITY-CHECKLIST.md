# Pre-launch security checklist
- [ ] Legal entity, target jurisdictions, licensing and compliance review.
- [ ] Real payment provider or independently verified blockchain settlement.
- [ ] Never collect/store private keys or seed phrases.
- [ ] Production database, backups, recovery tests and least-privilege access.
- [ ] Production session store, HTTPS, admin MFA, email verification and password reset.
- [ ] Audit logs, reconciliation, monitoring, incident response and support.
- [ ] Test duplicate callbacks, concurrent withdrawals, retries, access control and malicious input.
- [ ] Publish accurate fees, terms, privacy policy, complaints process and risk disclosures.
- [ ] Professional security review before handling real money.
